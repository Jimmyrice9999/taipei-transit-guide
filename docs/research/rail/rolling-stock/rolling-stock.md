## Car numbering convention

For TRTC high-capacity stock the **second digit of the car number encodes the
type**:

| Second digit | Type |
|---|---|
| 0 | C301 |
| 1 | C321 |
| 2 | C341 |
| 3 and 4 | C371 |
| 5 | C381 |

A small thing, but it means anyone can identify a fleet from a car number, and
nothing explains it in English.

# High-capacity fleets

## C301

| Field | Value |
|---|---|
| Builder | **Kawasaki Heavy Industries + URC (USA)** |
| Quantity | **44 units / 22 trains / 132 cars** |
| Depot | Beitou |
| Line | Tamsui–Xinyi |
| Formation | 6 cars |

**Taiwan's first standard-gauge train** — a genuine first worth stating.

**Propulsion renewal:** originally **Westinghouse GTO-VVVF**, replaced with
**Bombardier IGBT-VVVF** between **2013 and 2017**. This was the network's first
traction renewal programme.

## C321

| Field | Value |
|---|---|
| Builder | **Siemens** (SGP, Austria) |
| Quantity | **72 units / 36 trains / 216 cars** |
| Depots | Tucheng, Nangang |
| Line | Bannan |
| Propulsion | Siemens GTO-VVVF |

**A production defect worth documenting:** during manufacture the **body material
failed its strength specification** and showed **permanent deformation in
side-impact testing**. Siemens added material to compensate, so C321 left the
factory **heavier than C301** and with more angular bodysides.

**Propulsion renewal:** TRTC tendered in **February 2021**; bids opened **10 May
2021** with **four bidders — Taiwan Rolling Stock, Kuang Yun Machinery,
Bombardier and CAF (Spain)**; awarded **30 July 2021** to **Taiwan Rolling
Stock** using **ABB (Swiss) traction**. The network's second traction renewal
after C301.

## C341 — the best procurement story on the network

| Field | Value |
|---|---|
| Builder | **Siemens** (SGP, Austria) |
| Quantity | **12 units / 6 trains / 36 cars** |
| Depots | Tucheng, Nangang |
| Line | Bannan |
| Propulsion | **Siemens IGBT-VVVF** (not GTO like C321) |
| Formation | DM1–T–M2–M2–T–DM1 |
| Delivered | September–November 2004 |
| Entered service | January 2005 |

**This fleet was not procured by DORTS.** It was bought by **Continental
Engineering Corporation (大陸工程)**, the Tucheng line contractor.

Continental first tried to buy from **KOROS** — the Hyundai-Rotem / Daewoo joint
venture, now Hyundai Rotem. **DORTS refused.** Continental then bought from
Siemens instead, paying **NT$2.248 billion** for six six-car sets — roughly
**1.5× the per-car price DORTS itself had paid for C321**.

**A further quirk:** the sets initially **lacked side LED and line-colour
displays**, because those fell outside the warranty scope of the contract. They
were retrofitted later.

**Nobody has told this story in English.** A contractor forced to buy from a
supplier it didn't want, at 1.5× the price, for a fleet of six trains — that's a
complete article.

## C371 — the first Taiwanese-built metro train

| Field | Value |
|---|---|
| Builder | **Kawasaki Heavy Industries + Taiwan Rolling Stock Company** |
| Quantity | **107 units / 53.5 trains / 321 cars** |
| Depots | Xindian, Luzhou, Xinzhuang, Beitou |
| Lines | Songshan–Xindian, Xiaobitan branch, Zhonghe–Xinlu, Xinbeitou branch |
| Propulsion | Mitsubishi IGBT-VVVF |
| Contract | CK371 |

**The first metro EMU manufactured in Taiwan.**

Procurement: tendered 2003/2004 for **321 cars**. Bombardier, Siemens and Kawasaki
bid; **Kawasaki won**.

Build split:
- **First 159 cars** built at Kawasaki's Hyogo works, Japan
- **Remaining 162 cars built locally** with Taiwan Rolling Stock — **12 as SKD
  kits, 150 as complete local builds**

That local content was a deliberate industrial policy to build domestic
rail-manufacturing capability. **This is the origin of Taiwan Rolling Stock as a
metro builder**, and it leads directly to the C381 and the Circular Line fleet.

**Series:** split into a 3-series (123 cars) and a 4-series (198 cars) by build
year.

**Variants:** 52 six-car sets, plus **three three-car sets — 397, 398 and 399**
— for the **Xinbeitou and Xiaobitan branches**. Those two three-car operations are
the only ones on the network and should be covered together.

## C381

| Field | Value |
|---|---|
| Builder | **Kawasaki + Taiwan Rolling Stock** |
| Quantity | **48 units / 24 trains / 144 cars** |
| Lines | Songshan and Xinyi |
| Propulsion | Mitsubishi IGBT-VVVF (as C371) |
| Parts commonality with C371 | **≈50%** |

Design changes from C371: streamlined nose, **enlarged compound-curve
windscreen**, tapered side bands, skirt panels, and **anti-fall plates between
cars**.

## C382 — the newest fleet

| Field | Value |
|---|---|
| Builder | **Hyundai Rotem** |
| Quantity | **7 trains / 42 cars** |
| Purpose | Xinyi East Extension |
| Tendered | 2022 |
| Awarded | **November 2022** |

**Procurement detail:** after **two tenders**, only Hyundai Rotem bid. Note the
irony — Hyundai Rotem is the successor to KOROS, the manufacturer DORTS refused
to let Continental Engineering buy from in 2004.

Per TRTC's **March 2024** press release: first prototype delivered **2026**, all
testing complete by **2028**, **≈2,200 passengers per train**, **all-longitudinal
seating**, enlarged door recesses. Trains began arriving at Taipei Port from **May
2026**.

# Medium-capacity fleets

## Matra VAL256 — Wenhu

| Field | Value |
|---|---|
| Builder | **Matra Transport** (France), later Siemens |
| Fleet | **51 pairs / 102 cars / 25 trains** (contract CC350) |
| Depot | Muzha |
| Guidance | **Side guidance** via lateral H-section guide bars |
| Car width | **2,560 mm** |

**Key technical claim to verify:** the guide bars sit roughly **200 mm above the
running surface** and **also carry the 750 V supply**. Side guidance, not central
— this is a defining characteristic and a common error. VAL's *successor*
**NeoVal** genuinely is centrally guided, which explains how the mistake
propagates.

**Taipei was the first application of VAL256 coupled as two pairs into a four-car
set.** That first caused real problems: the two-car units were run as four
without a full control-system redesign, contributing to brake dragging and the
1993 test-track fire.

Siemens later acquired Matra's transport division, making VAL a Siemens product.

**Withdrawal:** reaches 40 years in **2036** and TRTC has confirmed it will **not
be life-extended**.

## Bombardier Innovia APM 256 / C370 — Wenhu

| Field | Value |
|---|---|
| Builder | **Bombardier** |
| Fleet | **101 pairs / 202 cars / 51 trains** (contract CB370) |
| Signalling | **CITYFLO 650** |
| Depot | Neihu |
| Car width | **2,540 mm** |

**Note the 20 mm width difference from VAL256.** The two fleets are commonly
described as interchangeable in dimensions; they are not.

Reached service with the Neihu section, **4 July 2009**.

**Fleet arithmetic check:** 51 + 101 = 152 pairs = **304 cars = 76 trains**,
matching the "all 76 trains" figure in the renewal reporting. Four-way
cross-check holds.

**Withdrawal:** the 51 Bombardier trains are to be replaced by **2039**.

## Circular Line fleet

| Field | Value |
|---|---|
| Builder | **Hitachi Rail Italy + Taiwan Rolling Stock** |
| Sets | **17**, four cars |
| Type | Medium-capacity, distributed traction, driverless |

Nose raked **20 degrees**, reportedly modelled on a dolphin. No external LED
displays. Anti-climbers on every car's lower body. Because the line has
full-height platform screen doors throughout, inter-car connections have **only
gangway bellows, no anti-fall devices**.

North/South Ring stock is a **new design** unveiled 3 November 2023 — bright
yellow, larger windows, exterior side destination displays, LCD passenger
information, bottom-mounted luggage racks at car ends.

## Sanying Line fleet

| Field | Value |
|---|---|
| Builder | **Hitachi Rail Italy** |
| Fleet | **29 cars** |
| Cars per train | **2** |

All delivered by September 2025. **Which Hitachi plant built them is disputed

## The incompatibility story

Taipei runs, on one metro network:

- **Two incompatible medium-capacity systems on a single line** (Matra VAL and
  Bombardier CITYFLO 650, both on Wenhu)
- **Steel-wheel high-capacity** on four lines
- **Light rail** on two New Taipei lines
- **A third medium-capacity system** on the Circular Line

This is a direct consequence of project-by-project procurement, where each line
was tendered separately with its own contractor and systems supplier. **It's the
single best framing for a `/rail/systems` article.**

## Checked and failed

Claims in this file verified against a source that did not survive. Kept here
rather than deleted, so the same lead is not chased twice.

- **"51 pairs / 25 trains" and "101 pairs / 51 trains"** — neither divides.
  Checked 7 August 2026, run 7. A four-car train is two pairs, so 25 trains need
  50 pairs and 51 trains need 102; both fleet counts here are odd. The totals do
  reconcile (152 pairs, 304 cars, 76 trains) but the per-fleet figures cannot
  both be train counts and pair counts of the same thing. The site publishes the
  arithmetic problem openly rather than picking a reading. Note zh.wikipedia
  describes the VAL256 as 「非固定編組」, which is one possible explanation and is
  not the one this file assumes.
- **"C370" used as the contract number** — the contract is **CB370**. Checked
  7 August 2026, run 7, against DORTS's own procurement FAQ, which gives
  木柵線 CC350 and 文湖線 CB370. C370 is the fleet designation, in the C301 /
  C321 / C341 / C371 / C381 series. Both names are correct for different things.
