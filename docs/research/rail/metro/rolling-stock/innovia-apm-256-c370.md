## Conflicts

- **Taiwan assembly: 101 versus 102 cars.** The August 2005 design article says `其中更有半數101輛車在台組裝`; the later full production report says `100輛將在匹茲堡組裝，其他102輛…由唐榮…負責組裝`. The page publishes both as design-stage and production-stage values and uses the later 100/102 split for the contract accounting.
- **Capacity at five standing passengers/m²: 372 versus approximately 386 per train.** DORTS's design table gives 93 people per car, hence 372 for four cars; TRTC's [current network introduction](https://www.metro.taipei/cp.aspx?n=ccf30033e6ed8008&s=405306CC7ACD137B) says `龐巴迪列車，每列車約可載運386人` at the same density. Neither full page explains the 14-person difference, so both values remain published.
