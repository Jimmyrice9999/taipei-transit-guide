# Tamsui–Xinyi Line 淡水信義線 (R)

**Version 2.0 — 10 August 2026.** Supersedes v1.0 (6 August 2026), which was
written from zh.wikipedia and a DORTS reading that had not been re-checked
against the page. Where v2.0 contradicts v1.0 it is because the DORTS page was
fetched in full and read.

**Method note, and it constrains everything below.** This run had **no web
search**: the session's search budget was already exhausted (200/200) before the
first query, so every source here was reached by walking DORTS and TRTC site
navigation outward from URLs already committed to this repository. That is why
there is not a single news-archive source in this file — 自由時報, 聯合報 and
中央社 were never reached. The primary coverage is good; the secondary coverage
is thin by accident, not by judgement. Anyone continuing this should start with
the news archives.

### The alignment, and the three-way structure split

**Source.** Tamsui–Xinyi Line — Tamsui section route description ·
淡水信義線／淡水線路線說明 · 臺北市政府捷運工程局 (DORTS) ·
<https://www.dorts.gov.taipei/cp.aspx?n=0AC527D5FC9E596A> (tab
`&s=A60BB323F07BC768`) · **PRIMARY** · confidence **High** — the builder's own
project record, one continuous sentence covering the whole alignment.

> 「淡水線北起淡水站沿原北淡鐵路南行至北投以北之貴子坑溪為地面段；自貴子坑溪堤起
> 高架南行跨基隆河，過民族西路下降進入地下至中正紀念堂站，全長約23.8公里(含北投至
> 新北投路段約1.2公里)，設22座車站及1座主機廠。」

Read carefully, because v1.0 read it backwards. The order along the line from
the north is: **at grade** from Tamsui as far as the Guizikeng Creek north of
Beitou; **elevated** from the Guizikeng embankment south across the Keelung
River; **underground** from after Minzu West Road to CKS Memorial Hall. The
at-grade running is the *northern* stretch, the inherited railway formation —
not a dip at the creek, which is how v1.0 described it.

Established from this one sentence:

- The Tamsui section is **約23.8 公里**, **including 約1.2 公里** of
  Beitou–Xinbeitou.
- **22 stations and one main depot** on the Tamsui section.
- It runs **沿原北淡鐵路** — along the former TRA Tamsui railway. This is the
  builder saying the corridor is inherited, in its own project record.
- Three structure types on one route: 地面 / 高架 / 地下.

**Also on that page** — 「另新北投支線為北投站至新北投站。」 — and, on the
earliest contract:

> 「最早CT107標北投機廠土方工程，自77年1月19日簽約開始施工。」

民國77年1月19日 = **19 January 1988**. Beitou Depot earthworks, contract CT107,
is the earliest construction contract signed on the project.

Same page, project framing: the whole initial network was approved by the
Executive Yuan on **民國75年4月4日** (4 April 1986) with a 核定總經費 of
**4,444 億元**; the Tamsui line ran to **13 design contracts (DT151–DT186)** and
about **120 construction contracts**. It is described there as
「國內第一條通車的高運量捷運系統」 — the first high-capacity metro line in
Taiwan to open.

### The Xinyi section

**Source.** Xinyi section route description · 信義線路線說明 · DORTS ·
<https://www.dorts.gov.taipei/cp.aspx?n=0ac527d5fc9e596a&s=CB7BC86DBDA1E44D> ·
**PRIMARY** · confidence **High**.

- **全長約6.4公里**, **7 座地下車站** — wholly underground.
- Alignment: east from CKS Memorial Hall across 金華街, 愛國東路 and 杭州南路,
  then along 信義路 into the 信義計畫區.
- 初勘 **13 October 2013**; 履勘 **8 November 2013**; 通車 **24 November 2013**.
- 路線規劃 approved by the Executive Yuan **民國86年11月21日** (21 November
  1997); 財務計畫 **民國93年10月22日** (22 October 2004); third amendment
  **民國102年8月6日** (6 August 2013). 總經費 **338.62 億元**.
- The seven stations DORTS counts: 中正紀念堂 (R08/G10), 東門 (R07/O06),
  大安森林公園 (R06), 大安 (R05/BR09), 信義安和 (R04), 台北101/世貿 (R03),
  象山 (R02).

**Note what that count includes.** 中正紀念堂 and 大安 already existed on other
lines. DORTS counts them because the Xinyi *project* built platforms there. Any
source giving a smaller number for "stations opened on 24 November 2013" is
counting a different thing, not disagreeing.

Reading the full table is the single cheapest next task in this file.

### Service patterns and headways, as operated now

**Source.** Routes and headways — Tamsui–Xinyi Line · 路線及班距／淡水信義線 ·
臺北大眾捷運股份有限公司 (TRTC) ·
<https://www.metro.taipei/cp.aspx?n=EAD981369A065968&s=1CC297E1D0B4C7B1> ·
**PRIMARY** · confidence **High** — the operator's own published service table,
read 2026-08-10.

營運模式: 「【淡水－象山】、【北投－大安】、【北投－新北投】」

| Pattern | Weekday peak | Weekday off-peak | After 23:00 | Weekend |
|---|---|---|---|---|
| 淡水–象山 / 北投–大安 | 約6分鐘，北投－象山區間約3分鐘 (07:00–09:00, 17:00–19:30) | 約8～10分鐘，重疊區間約4～5分鐘 | 約12分鐘（僅行駛【淡水－象山】模式） | 06:00–08:00 約8～10分鐘 (淡水–象山 only); 08:00–23:00 約8～10分鐘，重疊區間約4～5分鐘 |
| 北投–新北投 | 7～8分鐘 (06:30–09:00, 17:00–19:30) | 10分鐘 | 12～15分鐘 | 10～12分鐘 (06:00–23:00) |

行車時間: 【淡水－象山】約54分鐘; 【北投－大安】約32分鐘; 【北投－新北投】約3～4
分鐘.

Two things worth publishing out of this. First, **the second pattern today
terminates at 大安 (R05), not 北投–象山** as v1.0's 2013 table implies still
holds — so the 3-minute combined headway applies over 北投–象山 while the
short-working itself runs only to 大安. That is TRTC's own wording and it is
worth quoting rather than paraphrasing, because the two statements sit in the
same cell. Second, **the Xinbeitou shuttle is a published service pattern in its
own right**, with its own headway table and its own 3–4 minute running time.

The two DORTS figures meet end-to-end at CKS Memorial Hall, so summing them is
legitimate arithmetic — but it is *this file's* arithmetic and is labelled as
such, not quoted from anyone. That still leaves **2.1 to 3.3 km unaccounted for**
against zh.wikipedia's 32.3 km, and nothing read in this run explains the gap.
Candidates worth testing, none tested: the 1.4 km east extension already counted
in; tail tracks and depot leads counted in; a "total route length" measured on
the drawn alignment rather than on revenue track, which is precisely the
distinction that turned out to explain the Wenhu Line's three lengths. **Do not
pick one.**

### 2. Station count

- DORTS Tamsui section: **22**. DORTS Xinyi section: **7**. They share
  中正紀念堂, so 22 + 7 − 1 = **28**, which matches the stations in service today
  (R02–R28 is 27, plus R22A = 28). That reconciliation is this file's arithmetic
  on two primary figures; it is offered as a check, not as a published number.
- zh.wikipedia 淡水信義線 infobox: **29** — which is 28 plus the unopened R01.

These are not in conflict once you know what each counts. Recorded so nobody
"corrects" one to the other.

Ranked by how cheap they are to close.

1. **The rest of the DORTS station table.** Six rows were read. Reading all 22
