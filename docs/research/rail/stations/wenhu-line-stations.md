# Wenhu Line stations (BR01–BR06)

## Audit before editing

The preceding station-prose run left BR01–BR06 empty after checking the full
DORTS project, architecture and public-art pages. This batch widened the
search to the DORTS high-elevated-station volume, DORTS technical journals,
the DORTS land-development volumes, the official Taipei legal-system cost
record, and the current TRTC station pages. No public-art row for these six
stations was promoted: the fetched official Wenhu public-art table supplied no
station-specific row that survived this check. Bus-stop joins were not
published because the TDX join file is data, not a prose source, and no full
ebus/PTO route page was added in this batch.

## Conflicts

1. **Tunnel wording and extent:** The current DORTS project record describes
   the Muzha route as passing the north side of Xinhai Tunnel and also says the
   Muzha section is built entirely as elevated work. The DORTS technical
   journal instead says the line is elevated except for a tunnel in the Fuzhou
   Mountain area. These are both DORTS primary descriptions, and the pages do
   not define whether they are using different section boundaries or different
   route descriptions. BR05 publishes both rather than selecting one.

2. **Station engineering numbers versus operating codes:** The architecture
   volume lists the southern stations as engineering BR13, BR12, BR11, BR10,
   BR9 and BR8, while the current operating registry calls those stations BR01
   through BR06. These are different numbering systems, not competing current
   station names; the overlay keeps the engineering field separate from the
   operating code.

3. **Architecture source scope:** The architecture volume gives platform
   lengths and package groupings by engineering-era code, while the DORTS
   project table gives current station codes and addresses. The package claims
   above are mapped only where the two official tables identify the same
   station name; no contractor or value was inferred from the package number.

4. **Dazhi public-art status:** The DORTS public-art chapter’s topic summary
   lists `大直站：山水`, while its later executed-artwork list omits Dazhi and
   lists the works actually carried out at Songshan Airport, Jiannan Road,
   Xihu, Gangqian and Wende. The page does not say whether the Dazhi topic was
   cancelled, redesigned or only a planning label. The station page publishes
   the conflict and does not assert an installed Dazhi work.

5. **Neihu-section public-art topic versus execution records:** The same DORTS
   chapter’s topic summary lists B6 Market, B7 Recreation, B8 Dance, B9 Music,
   B10 Digital and B11 Light and Shadow. Its later executed-art list includes
   Dahu Park, Donghu and Nangang Exhibition Center, but omits B6 Neihu, B8
   Huzhou and B10 Nangang Software Park; the page separately says the original
   wall installations at Gangqian and Huzhou were cancelled after design
   changes because those walls were incomplete. The full official art table
   confirms rows for Dahu Park, Donghu and Nangang Exhibition Center, but no row
   for Neihu, Huzhou or Nangang Software Park was found in the checked table. No
   explanation is published for the B6 or B10 omissions, so the station pages
