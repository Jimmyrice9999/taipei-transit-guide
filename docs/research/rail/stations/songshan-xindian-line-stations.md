## Conflicts

1. **G15 Songjiang Nanjing platform form and exit count.** The DORTS station
   architecture article describes an underground three-level island-platform
   station and separately calls the G side side-platform and O side island-
   platform. The same article says the combined station has seven exits. The
   DORTS route table and the current TRTC page both publish eight exits. All
   values are retained: platform form is described as inconsistent in the page,
   and the current page uses eight for the operator’s street-exit count.

2. **G10 station name.** DORTS’s current New Store table prints
   `中正紀年堂站`, while the TRTC station page and the operator’s current name
   are `中正紀念堂`. The generated page uses the operator’s current name and
   records the DORTS spelling in its engineering-history note.

3. **Construction numbers versus operating codes.** DORTS’s route tables give
   G09 for operating G08, G10 for G09, G11 for G10, G12 for G11, and G13–G22
   with gaps for the Songshan stations. These are construction identifiers,
   not competing operating codes; both are shown where the source publishes
   them.

4. **Airport MRT connection classification.** DORTS describes the G13 Beimen
   connection to Airport MRT Taipei Main Station as an underground passage,
   while TDX does not carry an Airport MRT interchange code for G13. The page
   retains the builder’s named connection and leaves the paid/street mode TBC.

5. **Xiaobitan public-art cost scope.** DORTS’s planning manual gives an
   initial setup figure of NT$15 million and a NT$1 million first prize, while
   the later public-art record gives approximately NT$35.9 million plus a
   NT$1 million prize. The first value belongs to the compressed initial
   procurement/setup account; the second belongs to the later completed
   programme record. Both are published without reconciliation.
