## Conflicts

1. **Start date versus first service.** The TaiwanJobs profile lists 18 June 2002 as the establishment date, while its narrative dates the first Taipei route transfers from October 2002. These are different milestones in the same secondary profile and are not collapsed into one “founding” date.

2. **2010 operating scope versus the current page scope.** The Veterans Affairs article describes Taipei, Kaohsiung and remote-area services in 2010; the current page is only the Taipei municipality-scoped TDX record with 25 associations. The values describe different dates and scopes, not a unique-route total.

3. **Evaluation results.** The 2006 first-period municipal notice records 丙等 and a three-month route/vehicle action; the 113 second-period notice records 優等. Both values are published with their evaluation period and action, rather than resolved into a single rating.

4. **Operational location versus depot record.** The Route 207 display names 東南客運停車場, but it does not provide the depot fields required for a depot page. A named stop is retained as evidence of the display, not promoted to a complete depot record.
