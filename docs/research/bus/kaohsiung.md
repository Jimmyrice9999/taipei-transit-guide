## Conflicts

1. **Route count and counting unit:** the full municipal route index and full operator index each display 197 routes, while the full live TDX Route response contains 316 route records and 316 distinct route-name values. The municipal pages are public route indexes with operator/taxi/reservation grouping; TDX publishes a structured route-record population with branches and service variants. The fetched sources do not define a common counting unit, so the content page publishes both values and does not resolve them.
2. **Fare effective date:** the official fare page is titled `公車票價資訊(2026年7月1日起調整)` and its date is 115-06-30, but its internal table heading says `2026年3月1日起`. The linked official PDF says `實施時間：自 2026年7月1日起`. The page conflict is published; the PDF is not used to erase the contradictory HTML string.
3. **Operator population:** the municipal index groups routes under visible operator headings and reports 197 route entries, while TDX returns 30 operator records and attaches a different set of operator objects to 316 route records. These are different publication populations, not a contradiction to be averaged.
