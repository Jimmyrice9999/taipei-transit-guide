# Research corpus — index

**Built 7 August 2026, run 7.** Covers every file under `docs/research/`.

**This index is not a source and neither is anything it indexes.** The corpus is
a lead file. Nothing in it may be published on its own authority; publish the
underlying source it names, having read that source. Where the corpus says TBC,
it stays TBC.

The brief described 25 files. There are **21**. The four missing against the
framework's own map are listed in §5.

---

## 1. The files

Depth is judged against what a page could be *written* from, not length.
"Publishable now" means the corpus names a source specific enough to go and read.

### `rail/lines/wenhu-line.md` — 485 lines

**Covers.** The structural spine of the line: basics, the four length figures,
the three numbering systems with a full 24-row engineering-number table, the
complete station table with addresses and exit counts, the underground pair, the
alignment in detail for both sections, construction history for both projects
with contract structure and budgets, the 1993 incident, the Songshan Airport
station's late addition, the 區段標土木帶電機 procurement, station architecture,
and a rolling-stock conflict it correctly declines to resolve.

**Depth: the deepest file in the corpus, and the only one whose core is primary.**

**Strongest sources.** DORTS 文山內湖線 project page, and DORTS 車站建築設計. Both
verified verbatim during this run — see §3.

**Stated gaps.** The Innovia 101+51 manufacturing conflict; per-station ridership;
public art; whether the 麟光–劍南路 short working was ever scheduled; track gauge;
the Muzha groundbreaking year; station-by-station opening dates.

**Publishable now: a great deal, and most of it has been.** The engineering
numbers, the exit counts and the underground identification are all published in
this run.

### `rail/systems.md` — 266 lines

**Covers.** The project-by-project framing; signalling by line; the platform-door
rollout with completion dates; structure types across the network; the running
surfaces; power; automation grades; control centres; seismic design and the 403

**Depth: moderate, and unusually valuable per line.** It is a map of what the

## 3. Contradictions

Every disagreement found between the corpus and the site, and between the corpus
and the sources it names. Found by reading, not by machine — the site has no
checker for this and probably cannot have one.

### 3.1 Between the corpus and the sources it cites

**(a) The 車站建築設計 URL in `wenhu-line.md` is wrong.** The file cites
`cp.aspx?n=980C85299DA2890A`. That lands on a general overview carrying two
sentences and none of the quoted material. The page the file is actually quoting
is `cp.aspx?n=980C85299DA2890A&s=6B0F524CA1EB5C9F` — the same node with its
sub-section id. Anyone following the citation as written would conclude the
research had invented the quotations. **The site now cites the correct URL.**

**(b) `wenhu-line.md` says the Muzha section is "entirely elevated"; so does
DORTS. `wenhu-research-part2.md` §5 puts a Fuzhou Mountain Tunnel on the same
route.** DORTS's own alignment text reads 「穿越辛亥隧道北側接和平東路」 — passing
the *north side* of the Xinhai road tunnel — and closes 「全線以高架方式興建」,
built entirely as elevated. zh.wikipedia reads 「穿越福州山隧道後，再沿著和平東路」,
through the Fuzhou Mountain Tunnel. Those are not the same claim. Between BR05
Xinhai and BR06 Linguang the line has to cross a ridge, and the two sources
disagree about how. **Unresolved.** The site follows the primary and says so in
the elevation profile's caption.

**(c) `wenhu-line.md`'s own Basics table gives the line as "≈25.7 km" while its
length section says to publish 25.17 km.** Internal to the corpus; the site is
right.

**(d) The fleet arithmetic does not divide, and no file notices.** 51 pairs of
VAL and 101 pairs of Innovia. Four-car trains are two pairs. 51 is odd and 101 is
odd, so **neither fleet alone forms a whole number of four-car trains**; only the
sum does (152 pairs = 76 trains). `rolling-stock.md` prints "51 pairs / 25 trains"
and "101 pairs / 51 trains" — 25 × 2 = 50 pairs, 51 × 2 = 102 pairs, and neither
matches its own pair count. Either a pair is stabled spare in each fleet, or at
least one train is formed across both fleets. **If it is the second, the site's
framing of the two fleets as separated at formation level is wrong.** This has
been open since run 3 and the corpus reproduces the arithmetic without flagging
it. It is the sharpest unresolved question in the whole corpus.

**(e) `ankeng-lrt.md` contradicts itself on structure.** NTMC describes the line
as elevated and at-grade only; zh.wikipedia's alignment breakdown includes

### What needs archiving

**Fourteen government CMS URLs.** Every `cp.aspx?n=<hex>` and
`News_Content.aspx?n=<hex>&s=<hex>` above. A node id is not a searchable string:
if the CMS is rebuilt, the citation is unrecoverable rather than merely stale.

`npm run archive` was run against the site's own source list this run; its result
is in the run log. The corpus URLs that are not yet cited on the site cannot be
archived by that command, because it reads the site's citations rather than the
research. **That is the right design** — archiving a URL nobody has read yet
records a page, not a claim — but it means the corpus's own reading list is
unprotected until each item is actually used.
