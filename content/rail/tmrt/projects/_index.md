The [land development record](/rail/tmrt/projects/joint-development/)
covers Taichung's own metro land-development mechanism and seven named
Green Line station sites, each with a real investor, site figures and a
dated procedural timeline — a working case list, unlike the equivalent
pages this project found for Kaohsiung and Taoyuan.
